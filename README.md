### PC Controls for Castle Master 3D

- Left click - move to point / select NPC or monster
- Right-click drag - rotate + pitch camera around player
- Scroll wheel - zoom (FOV 30-60)
- 1/2/3/4/5 (battle HUD) - use HP item / MP item / skill 1 / skill 2 / skill 3

**World map:**

Left click drag - pan map
Scroll wheel - toggle zoom in/out (two-levels, not continuous)
